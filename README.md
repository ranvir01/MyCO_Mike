# Gadget Fix / MyCo consulting deliverables

Consulting package for **Gadget Fix** (phone repair, Kent, WA) produced through MyConsulting Network.

**Core insight:** repair cracked devices to unlock higher carrier/Apple trade-in values (documented with verified market data).

## What is in this repo

- Business plan and pricing packages
- HTML landing pages and interactive **trade-in calculator**
- Carrier partnership pitch materials and comparison tools
- Marketing content, meeting slides, outreach playbooks
- **12-agent coordinator workflow** (`AGENT_PROMPTS/`) for parallel research, build, and QA

## Start here

1. `GADGET_FIX_MASTER_DELIVERABLES.md` — deliverable index
2. `AGENT_PROMPTS/00_AGENT_COORDINATOR_README.md` — multi-agent methodology
3. `trade_in_calculator.html` / landing page HTML files — open locally in a browser

## How to frame this portfolio piece

This is **consulting ops + AI orchestration**, not a single SaaS product. It shows scoping, research discipline, client-facing PM, and agent-assisted delivery with human QA.
